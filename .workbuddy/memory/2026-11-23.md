# 2026-11-23

## 广域网下载页新增「用 WorkBuddy 自动安装」提示词区块

### 需求澄清过程（重要）

用户原话「增加 workbuddy 使用说明」+ 一段文字，最初被误解为面向访客的安装步骤。
**实际含义**：WorkBuddy 是一个 AI 工具，那段文字是**给 AI 执行的提示词**，
页面要做的是让访客能把它复制给 WorkBuddy 自动完成安装登录。

确认结论：① 给访客看的（不是机器可读的 llms.txt）② 需要复制按钮 ③ 加安全提示。

### 实现

- 新增 `components/CopyButton.tsx`（`'use client'`，下载页其余部分仍是服务端组件）：
  优先 `navigator.clipboard`，失败回退隐藏 textarea + `execCommand`（兼容纯 http），
  复制成功后按钮文案切换 2 秒，卸载时清定时器。
- `app/[locale]/download/page.tsx`：在 `#server` 区块的卡片网格**下方**新增
  `glass-card`，含标题、引导语、`<pre>` 提示词原文、右上角复制按钮、底部安全提示。
  `lg:max-w-3xl` 与上方网格对齐。不占 ①② 步骤编号。
- i18n：`download` 命名空间新增 6 个 key（`workbuddyTitle/Lead/Prompt/Copy/Copied/Safety`），
  中英各一份。中文提示词**逐字照抄**用户原文，保留【你的用户名】【你的密码】标记。

### 注意

- `<pre>{t('workbuddyPrompt')}</pre>` 必须与标签同书写，否则会带入首行缩进。
- 复制的是 `t()` 原文，不含任何渲染空白。
- `lan-download` 页面不渲染该区块；其 HTML 里出现 "WorkBuddy" 只是 next-intl
  把整份 messages 序列化进 RSC payload 导致的，非可见内容。

### 英文版提示词替换（同日）

英文提示词换成更可执行的版本：指定 WAN 版 Sunshine（Windows AMD64 installer，
非 Moonlight）、要求管理员权限与 UAC 放行、命令行工具 `sunshine_config.exe`
**bind 而非 register**、密码走 stdin、用工具自带的 `restart` 命令重启，
最后回报服务状态 / 登录用户 / device_id。

- 原文粘贴时带硬换行，已合并为单段（`<pre>` 用 `whitespace-pre-wrap`，
  保留硬换行会在宽屏上产生奇怪的断行）。
- 提示词内含双引号，JSON 中需转义，复制出去的值仍为正常引号。
- 同步把 `workbuddyLead` 的占位符说明从【your username】改成
  `YOUR_USERNAME` / `YOUR_PASSWORD`，与新提示词一致。
- 中文版提示词**未改**，两版语义目前不一致（中文仍是泛化描述）。
